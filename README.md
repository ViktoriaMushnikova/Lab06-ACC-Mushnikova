После запуска программы выделяется рабочая область в оперативной памяти, поэтому её использование растёт, а во время вычислений процессор активно выполняет инструкции, из-за чего загрузка CPU резко возрастает.
## Итоговый вопрос
Нельзя просто сказать, что процессор запускает программу напрямую с накопителя, потому что накопитель предназначен для долговременного хранения файлов, а процессор работает с данными из оперативной памяти. Операционная система загружает программу с накопителя в оперативную память и создаёт процесс, а оперативная память хранит код и рабочие данные запущенной программы, чтобы процессор мог быстро выполнять инструкции.
## Контрольные вопросы
1. Файл программы на накопителе - это просто сохранённые на диске данные, а процесс  - это уже запущенная копия программы в памяти, которой управляет операционная система и которой присваивается PID.
2. После запуска оперативная память нужна, чтобы хранить код программы, рабочие данные и выделенную процессу область памяти для быстрой работы инструкций.
3. По Диспетчеру задач видно, что в списке процессов появляется строка программы со статусом выполняется и своим PID, выделяется память, а при нагрузке растёт использование CPU.
 4. Во время вычислений процессор активно выполняет инструкции программы, поэтому нагрузка на CPU увеличивается.
 5. Да, файл программы на накопителе остаётся, а процесс после завершения работы исчезает из памяти.
## Итоговый вывод
До запуска программа хранится на накопителе SSD, где файлы лежат в сохранённом виде. При запуске операционная система загружает программу в оперативную память RAM и создаёт процесс со своей рабочей областью памяти и идентификатором. Дальше процессор CPU берёт инструкции этого процесса из оперативной памяти и выполняет вычисления, повышая свою загрузку. После закрытия программы процесс удаляется из оперативной памяти, а сам файл программы остаётся на накопителе.
